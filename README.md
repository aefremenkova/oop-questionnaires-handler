# Обработчик анкет
 
Программа читает файл с анкетами (имя задаётся в файле с настройками config.py), 
осуществляет валидацию данных и их форматирование, выводит результат - таблица принятых
записей, список отклонённых записей с причинами, аналитика, имена файлов с 
сохранёнными записями
 
## Запуск
```
python main.py
```
 
## Формат входного файла
тип;ФИО;почта;телефон;группа или кафедра
где тип s - студент, t - преподаватель;
группа - у студентов (тип s), кафедра - у преподавателей (тип t).
